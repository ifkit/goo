# Crafted hints for AI commonly known as "skills"

## Install

Claude Code:

    /plugin marketplace add ifkit/goo
    /plugin install goo@goo

Codex:

    codex plugin marketplace add ifkit/goo

Gemini CLI:

    gemini extensions install https://github.com/ifkit/goo

Other agents (Copilot, OpenCode, Amp, and others that read the Agent Skills format):

    npx skills add ifkit/goo
